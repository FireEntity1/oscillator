Oscillator is a basic and easy to use program for experimenting with making chord progressions and melodies. The goal of oscillator is to allow the user to play around with music to get ideas to make music!

## Features
- A piano roll-like interface for creating melodies
- A simple way to play chords where the user can simply enter a chord name (like `Gm` or even something like `Ebmaj7/B` and the program will parse and play!
- Support for multiple instruments
- Ability to customize each instrument
- Detune and unison for waves
## Future Plans
